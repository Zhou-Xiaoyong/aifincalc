常见问题

社保缴费基数是什么？

社保缴费基数是计算社会保险费的基础，通常为职工本人上年度月平均工资。各城市都有缴费基数的上下限，一般在当地社平工资的60%-300%之间。

五险一金包括哪些？

五险一金包括：养老保险、医疗保险、失业保险、工伤保险、生育保险（五险）和住房公积金（一金）。其中工伤保险和生育保险由单位全额缴纳，个人不缴费。

住房公积金缴纳比例是多少？

住房公积金缴纳比例一般在5%-12%之间，具体比例由单位和个人协商确定。单位和个人缴纳比例相同，全部计入个人账户。

一、输入项详细说明

🏙️ 所在城市

选择您所在的城市后，系统会自动带入该城市最新的社保缴费比例。目前支持北京、上海、广州、深圳、杭州、南京、成都、武汉、西安9个主要城市的社保政策。不同城市的社保缴费比例和基数上下限存在差异，选择正确的城市可以确保计算结果的准确性。

💰 社保缴费基数

社保缴费基数是计算社会保险费的基础数据。一般来说，缴费基数等于职工本人上年度月平均工资。但各城市都会设定缴费基数的上下限：

  • 缴费基数下限：通常为当地上年度职工月平均工资的60%
  • 缴费基数上限：通常为当地上年度职工月平均工资的300%

如果您的工资低于下限，按下限缴纳；高于上限，按上限缴纳。

📊 养老保险

养老保险是社会保障制度的重要组成部分，用于保障职工退休后的基本生活。

  • 个人缴纳比例：一般为8%，全部计入个人账户
  • 单位缴纳比例：一般为16%，计入统筹基金
  • 领取条件：累计缴费满15年，达到法定退休年龄

🏥 医疗保险

医疗保险用于保障职工的基本医疗需求，减轻医疗费用负担。

  • 个人缴纳比例：一般为2%
  • 单位缴纳比例：一般为8%-12%（各地不同）
  • 个人账户：个人缴费全部计入，单位缴费按一定比例划入

💼 失业保险

失业保险为失业人员提供基本生活保障，帮助其重新就业。

  • 个人缴纳比例：一般为0.2%-0.5%
  • 单位缴纳比例：一般为0.5%-1%
  • 领取条件：累计缴费满1年，非本人意愿中断就业

🛡️ 工伤保险

工伤保险为因工作遭受事故伤害或患职业病的职工提供医疗救治和经济补偿。

  • 个人缴纳比例：0%（个人不缴费）
  • 单位缴纳比例：0.2%-1.9%（按行业风险等级确定）
  • 特点：全部由单位缴纳，个人无需承担

👶 生育保险

生育保险为女职工提供生育期间的医疗服务和生育津贴。

  • 个人缴纳比例：0%（个人不缴费）
  • 单位缴纳比例：0.5%-1%
  • 待遇：生育医疗费用报销 + 生育津贴

🏠 住房公积金

住房公积金是一种住房保障制度，用于帮助职工解决住房问题。

  • 个人缴纳比例：5%-12%（由单位确定）
  • 单位缴纳比例：与个人相同
  • 特点：单位和个人缴纳的部分全部计入个人账户，归个人所有
  • 用途：购房贷款、提取支付房租、装修等

二、社保计算公式详解

📝 个人缴纳金额计算

个人缴纳金额 = 缴费基数 × 个人缴费比例

个人缴纳项目及比例（以北京为例）：

险种 个人比例 说明
养老保险8%计入个人账户
医疗保险2%计入个人账户
失业保险0.5%计入统筹基金
工伤保险0%个人不缴费
生育保险0%个人不缴费
住房公积金12%计入个人账户

💼 单位缴纳金额计算

单位缴纳金额 = 缴费基数 × 单位缴费比例

单位缴纳项目及比例（以北京为例）：

险种 单位比例 说明
养老保险16%计入统筹基金
医疗保险10%统筹+个人账户
失业保险0.5%计入统筹基金
工伤保险0.5%按行业风险
生育保险0.8%计入统筹基金
住房公积金12%计入个人账户

📊 五险一金总缴纳计算

总缴纳金额 = 个人缴纳总额 + 单位缴纳总额

个人缴纳总额 = 养老 + 医疗 + 失业 + 公积金

单位缴纳总额 = 养老 + 医疗 + 失业 + 工伤 + 生育 + 公积金

注：工伤保险和生育保险仅由单位缴纳，个人不承担这两项费用。

三、使用案例

📌 案例一：北京上班族社保计算

案例背景：张先生，北京工作，社保缴费基数10,000元，住房公积金缴纳比例12%。

输入数据：

  • 所在城市：北京
  • 社保缴费基数：10,000元
  • 养老保险：个人8%，单位16%
  • 医疗保险：个人2%，单位10%
  • 失业保险：个人0.5%，单位0.5%
  • 工伤保险：个人0%，单位0.5%
  • 生育保险：个人0%，单位0.8%
  • 住房公积金：个人12%，单位12%

计算过程：

  • 个人缴纳：
  • 养老保险 = 10000 × 8% = 800元
  • 医疗保险 = 10000 × 2% = 200元
  • 失业保险 = 10000 × 0.5% = 50元
  • 住房公积金 = 10000 × 12% = 1,200元
  • 个人合计 = 800 + 200 + 50 + 1200 = 2,250元
  • 单位缴纳：
  • 养老保险 = 10000 × 16% = 1,600元
  • 医疗保险 = 10000 × 10% = 1,000元
  • 失业保险 = 10000 × 0.5% = 50元
  • 工伤保险 = 10000 × 0.5% = 50元
  • 生育保险 = 10000 × 0.8% = 80元
  • 住房公积金 = 10000 × 12% = 1,200元
  • 单位合计 = 1600 + 1000 + 50 + 50 + 80 + 1200 = 3,980元

总缴纳 = 2,250 + 3,980 = 6,230元/月

📌 案例二：深圳高新技术企业员工

案例背景：李女士，深圳工作，社保缴费基数25,000元（深圳市社保上限），住房公积金缴纳比例5%（单位按最低比例缴纳）。

输入数据：

  • 所在城市：深圳
  • 社保缴费基数：25,000元
  • 养老保险：个人8%，单位15%
  • 医疗保险：个人2%，单位6.2%
  • 失业保险：个人0.5%，单位0.5%
  • 工伤保险：个人0%，单位0.4%
  • 生育保险：个人0%，单位0.45%
  • 住房公积金：个人5%，单位5%

计算结果：

  • 个人缴纳 = 25000 × (8%+2%+0.5%+5%) = 25000 × 15.5% = 3,875元
  • 单位缴纳 = 25000 × (15%+6.2%+0.5%+0.4%+0.45%+5%) = 25000 × 27.55% = 6,887.5元
  • 总缴纳 = 3,875 + 6,887.5 = 10,762.5元/月

📌 案例三：公积金缴纳比例对收入的影响

案例背景：王先生，杭州工作，社保缴费基数15,000元。公司提供两种公积金缴纳方案：5%和12%，让员工自行选择。

方案一：公积金缴纳5%

  • 个人缴纳 = 15000 × (8%+2%+0.5%+5%) = 15000 × 15.5% = 2,325元
  • 到手工资（税前15000-社保个人部分）≈ 12,675元
  • 公积金账户 = 15000 × 5% × 2 = 1,500元/月

方案二：公积金缴纳12%

  • 个人缴纳 = 15000 × (8%+2%+0.5%+12%) = 15000 × 22.5% = 3,375元
  • 到手工资（税前15000-社保个人部分）≈ 11,625元
  • 公积金账户 = 15000 × 12% × 2 = 3,600元/月

对比分析：

  • 选择12%公积金，每月到手少1,050元，但公积金账户多2,100元
  • 相当于每月多存2,100元（其中单位补贴1,050元）
  • 建议：如果有购房计划，选择12%更划算；如果现金流紧张，可选择5%
