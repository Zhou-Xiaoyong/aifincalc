月薪1万5到手多少钱？2026年五险一金和个税这样扣

👁 0 阅读 ⏱ 阅读约6分钟

月薪1万5到手多少钱？这是几乎每个拿到1.5万月薪的人都会算的一笔账。答案不是固定的——它取决于你所在城市的五险一金比例，以及专项附加扣除填了多少。下面用真实数字把这道题算透，你看完就能对着自己的工资条估出准数。

先说结论，免得你往下划得累：在绝大多数一线城市的常规缴纳比例下，月薪1.5万税后到手大致在 1.1万到1.16万 之间。扣得最狠的那种（公积金顶格12%、又没填报任何扣除）也就掉到1.1万出头；公积金比例低、再把“一老一小”的专项附加扣除填上，能摸到1.16万。下面拆开看钱都去哪了。

一、先给结论：月薪1万5，到手大概落在1.1万到1.16万

到手工资就一个公式：到手 = 税前工资 − 五险一金个人部分 − 个人所得税。前半截五险一金是“强制储蓄”（养老、医疗、失业、公积金，公积金还是你自己的钱），后半截个税才真正是交给国家的税。想搞清楚自己那笔，只要把这两项分别算明白就行。

2026年个税起征点仍是 每月5000元（一年6万），这一条从2019年施行至今没动过。税率是综合所得3%到45%的七级超额累进——月薪1.5万这种中高收入，全年算下来基本落在10%这一档，不会触到更高的税率。所以真正拉开到手差距的，是五险一金里那个浮动最大的公积金比例。

二、五险一金和个税怎么扣（逐项拆给你看）

五险一金的个人缴纳比例是法定+单位协商的混合体：养老 8%、医疗 2%、失业 0.5% 是全国统一的个人部分；公积金在 5%—12% 之间，由你单位在范围内确定。把这几项加起来，个人五险一金合计大约在 17.5%—22.5%。

以月薪15000元、公积金按12%顶格交为例：养老1200 + 医疗300 + 失业75 + 公积金1800 = 3375元/月，占工资22.5%。如果单位公积金只交7%，个人五险一金就降到2625元。这750元的差距，会直接、全额地体现在你的到手工资里。

个税这一块用累计预扣法：不是每月单独算，而是把今年到当前月份的收入、减除费用、五险一金、专项附加扣除一路累加，用“累计应纳税所得额”套税率，再减去前面几个月已经预缴的，才是当月实缴。后文会解释为什么这套算法会让你感觉“个税越扣越多”。

三、算笔账：公积金按12%扣，两种情形差出近400元/月

还是月薪15000、五险一金个人3375元/月，分两种情形算全年个税：

情形A：不填任何专项附加扣除。 全年应纳税所得额 = 15000×12 − 5000×12 − 3375×12 = 180000 − 60000 − 40500 = 79500元。落在3.6万—14.4万这一档，税率10%、速算扣除2520，全年个税 = 79500×10% − 2520 = 5430元，月均452.5元。到手 = 15000 − 3375 − 452.5 = 11172.5元/月。

情形B：填了赡养老人（独生3000/月）+ 子女教育（2000/月）。 一年专项附加扣除多了 (3000+2000)×12 = 60000元。全年应纳税所得额 = 180000 − 60000 − 40500 − 60000 = 19500元，只落进最低的3%档，全年个税 = 19500×3% = 585元，月均48.75元。到手 = 15000 − 3375 − 48.75 = 11576.25元/月。

两种情形一比，光是填不填专项附加扣除，每月到手就差 403.75元，一年差出 4845元。这钱本来就是你的，不填等于白白多交税。想知道自己能填几项、每项扣多少，直接看个人所得税计算器里的专项附加扣除栏目，照着工资条勾一遍最省事。

四、个税累计预扣法为什么越扣越多（年中跳档）

不少人吐槽：“前几个月个税才一百多，年中突然变四百多，工资是不是算错了？”不是算错，是累计预扣法在跳档。接着用情形A的数字演一遍：

每月累计应纳税所得额 = (15000 − 5000 − 3375) × 月份数 = 6625 × 月数。
第1到第5个月：累计都没超过3.6万，一直按3%，每月个税都是 6625×3% = 198.75元。
第6个月：累计到39750元，越过3.6万的门槛进了10%档，当月个税 = 39750×10% − 2520 − 已预缴993.75 = 461.25元。
第7个月到年底：仍在10%档内，当月个税稳定在 662.5元/月。

所以到手工资从第6个月起明显“缩水”——前5个月每月到手11426元，第6个月11164元，下半年稳定在10963元左右。全年总个税还是5430元，只是前低后高地分摊，导致年中那一下看着扎心。工资越高、跳档越猛，这个现象越明显。

五、工资1万5到手1万1正常吗（给你一个判断区间）

1.1万完全正常，它甚至就是“扣得最狠”那一档的底线。判断标准很简单：

低于1.1万：先核对公积金比例是不是顶格12%，以及专项附加扣除有没有漏填。如果两项都正常还不到1.1万，可能是年终奖或补贴并入当月、把税率顶高了。
1.1万—1.13万：公积金12%但填了部分专项附加扣除，最常见。
1.13万—1.16万：公积金比例较低（7%左右），或扣除项填得全，属于“会交税”的那拨人。
只要落在这个区间里都不用慌，差异基本都来自五险一金和扣除项，不是财务算错了。

❓ 常见问题（FAQ）

Q：月薪1万5到手多少钱？

A：以月薪15000元、五险一金个人部分按22.5%（公积金顶格12%）扣除为例：每月扣五险一金约3375元，无专项附加扣除时全年个税5430元、月均452.5元，到手约11172.5元/月；若填了赡养老人+子女教育等专项附加扣除，到手能升到约11576元/月。公积金比例越低、扣除项越多，到手越高。

Q：五险一金和个税怎么扣？

A：到手工资 = 税前工资 − 五险一金个人部分 − 个人所得税。五险一金个人部分 = 养老8% + 医疗2% + 失业0.5% + 公积金（5%—12%，由单位确定），合计约17.5%—22.5%。个税用累计预扣法：每月先用“累计收入 − 累计减除费用5000×月数 − 累计五险一金 − 累计专项附加扣除”算累计应纳税所得额，再套3%—45%七级税率，减去已预缴的才是当月实缴。

Q：个税累计预扣法为什么越扣越多？

A：因为累计预扣法按“累计应纳税所得额”跳档计税。仍以月薪1.5万、公积金12%为例：前5个月累计应纳税所得额没超过3.6万，都按3%扣，每月个税198.75元；到第6个月累计超过3.6万，进入10%档，当月个税跳到461.25元；第7个月起到年底稳定在662.5元/月。这就是很多人感觉“年中工资突然变少”的原因，全年总税额不变，只是按月分摊时前低后高。

Q：工资1万5到手1万1正常吗？

A：正常。1.1万是公积金按12%顶格交、又没填专项附加扣除时的“下限”。公积金比例降到7%、或填了赡养老人、子女教育、房贷利息等扣除后，到手会升到1.13万—1.16万。所以到手在1.1万到1.16万之间都属合理区间，低于1.1万要核对一下公积金比例是不是偏高或专项附加扣除漏填了。
