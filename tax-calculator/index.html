常见问题

个税起征点是多少？

2025年个人所得税起征点为每月5000元，年度60000元。

专项附加扣除有哪些？

包括子女教育（2000元/月）、继续教育（400元/月）、住房贷款利息（1000元/月）、住房租金（1500元/月）、赡养老人（最高3000元/月）、3岁以下婴幼儿照护（2000元/月）。

年终奖如何计税？

年终奖可以选择单独计税或并入综合所得计税，本计算器默认按单独计税方式计算。

📖 个税计算器使用指南

一、输入项详细说明

💰 所在城市

选择您所在的城市后，系统会自动带入该城市最新的社保缴费比例。目前支持北京、上海、广州、深圳、杭州、南京、成都、武汉、西安9个城市的社保政策。不同城市的社保缴费比例和基数上下限存在差异，选择正确的城市可以确保计算结果的准确性。

💼 税前月薪

指您每月的应发工资总额，包括基本工资、绩效工资、奖金、津贴等所有计入工资总额的收入项目。这是计算个税的基础数据，请准确输入。

📊 社保公积金缴纳基数

社保和公积金的缴纳基数，通常等于或低于税前工资。如果不填写，系统默认按税前工资作为缴费基数。部分单位可能按照当地最低工资标准或其他基数缴纳，此时需要手动输入实际缴费基数。

📈 社保缴费比例

包括养老保险（8%）、医疗保险（2%）、失业保险（0.5%）、住房公积金（5%-12%）。这些比例是个人缴纳部分，单位缴纳部分不计入个人扣款。不同城市的比例可能略有差异，系统会根据您选择的城市自动调整。

🏠 专项附加扣除

根据《个人所得税法》规定的6项专项附加扣除：

  • 子女教育：每个子女每月2000元，适用于3岁以上至全日制学历教育阶段
  • 继续教育：每月400元，最长不超过48个月
  • 住房贷款利息：每月1000元，最长不超过240个月
  • 住房租金：按城市规模分为1500元/1100元/800元三档
  • 赡养老人：独生子女每月3000元，非独生子女分摊每人不超过1500元
  • 3岁以下婴幼儿照护：每个婴幼儿每月2000元

注意：住房贷款利息和住房租金两项不能同时享受。

📋 其他扣除

包括企业年金、职业年金、商业健康保险、税收递延型商业养老保险等符合税法规定的其他扣除项目。

二、个税计算公式详解

📝 应纳税所得额计算

应纳税所得额 = 税前工资 - 五险一金 - 专项附加扣除 - 其他扣除 - 起征点(5000元)

其中：五险一金 = 缴费基数 × (养老保险比例 + 医疗保险比例 + 失业保险比例 + 住房公积金比例)

💸 应缴个税计算

应缴个税 = 应纳税所得额 × 适用税率 - 速算扣除数

个人所得税采用超额累进税率，共7级，税率从3%到45%。具体税率表如下：

级数 全年应纳税所得额 税率 速算扣除数
1不超过36,000元3%0
2超过36,000至144,000元10%2,520
3超过144,000至300,000元20%16,920
4超过300,000至420,000元25%31,920
5超过420,000至660,000元30%52,920
6超过660,000至960,000元35%85,920
7超过960,000元45%181,920

注：月度计算时，需将月度应纳税所得额换算为全年金额查表，再换算回月度税额。

💰 实发工资计算

实发工资 = 税前工资 - 五险一金 - 应缴个税

三、使用案例

📌 案例一：普通上班族个税计算

案例背景：张先生，北京工作，税前月薪15,000元，社保缴费基数15,000元，住房公积金缴纳比例12%。已婚，有一个上小学的孩子，夫妻双方共同扣除子女教育；有住房贷款；父母均已退休，为独生子女。

输入数据：

  • 所在城市：北京
  • 税前月薪：15,000元
  • 社保缴费基数：15,000元
  • 养老保险：8%
  • 医疗保险：2%
  • 失业保险：0.5%
  • 住房公积金：12%
  • 专项附加扣除：子女教育1000元 + 住房贷款利息1000元 + 赡养老人3000元 = 5000元

计算过程：

  • 五险一金 = 15000 × (8%+2%+0.5%+12%) = 15000 × 22.5% = 3,375元
  • 应纳税所得额 = 15000 - 3375 - 5000 - 5000 = 1,625元
  • 应缴个税 = 1625 × 3% = 48.75元（全年应纳税所得19,500元，适用3%税率）
  • 实发工资 = 15000 - 3375 - 48.75 = 11,576.25元

📌 案例二：高收入人群个税计算

案例背景：李女士，上海工作，税前月薪50,000元，社保缴费基数35,000元（上海市上限），住房公积金缴纳比例7%。单身，有住房租金支出（上海属于直辖市，扣除标准1500元），正在攻读在职研究生。

输入数据：

  • 所在城市：上海
  • 税前月薪：50,000元
  • 社保缴费基数：35,000元
  • 养老保险：8%
  • 医疗保险：2%
  • 失业保险：0.5%
  • 住房公积金：7%
  • 专项附加扣除：住房租金1500元 + 继续教育400元 = 1900元

计算过程：

  • 五险一金 = 35000 × (8%+2%+0.5%+7%) = 35000 × 17.5% = 6,125元
  • 应纳税所得额 = 50000 - 6125 - 1900 - 5000 = 36,975元
  • 全年应纳税所得 = 36975 × 12 = 443,700元，适用30%税率，速算扣除数52,920元
  • 年度应缴个税 = 443700 × 30% - 52920 = 80,190元
  • 月度应缴个税 = 80190 ÷ 12 ≈ 6,682.5元
  • 实发工资 = 50000 - 6125 - 6682.5 = 37,192.5元

📌 案例三：年终奖个税计算与优化

案例背景：王先生，年度工资收入24万元，年终奖8万元。有两种计税方式可选：单独计税或并入综合所得计税。

方案一：年终奖单独计税

  • 年终奖税额 = 80000 × 10% - 210 = 7,790元
  • 工资部分应纳税 = (240000 - 60000) × 20% - 16920 = 21,080元
  • 合计应纳税 = 7790 + 21080 = 28,870元

方案二：年终奖并入综合所得

  • 全年总收入 = 240000 + 80000 = 320,000元
  • 应纳税所得额 = 320000 - 60000 = 260,000元
  • 应纳税 = 260000 × 20% - 16920 = 35,080元

结论：选择单独计税可节省6,210元（35080 - 28870），因此单独计税更优。
